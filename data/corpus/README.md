# Corpus data

Seed corpora for the exercise and meal systems (specs/corpus.md). Canonical units: kg, meters, seconds; nutrition per 100g (g / kcal; mg and µg where suffixed).

## Files

- `exercises.json` — canonical exercise library. Generated by Sonnet agent fan-out (territory generators → merge/dedup → enrichment → critic sweeps until dry), schema-validated by `scripts/corpus/validate.mjs`. Built 2026-07-27.
- `ingredients.json` — whole-food macros + micros + household portions. Source: USDA FoodData Central (SR Legacy 2018-04 + Foundation Foods 2025-04-24 bulk CSVs). **Public domain (CC0).** Parsed by `scripts/corpus/parse-fdc.mjs`.
- `products.json` — top US products by scan popularity: barcode, macros, ingredient text, additives, allergens, labels, NOVA, Nutri-Score, and `flags[]` (AI classifier; `null` = unclassified, `[]` = classified clean). Source: Open Food Facts full export. **ODbL — Open Food Facts contributors, https://world.openfoodfacts.org; database license https://opendatacommons.org/licenses/odbl/1-0/. Attribution required in any user-facing surface using this data.** Parsed by `scripts/corpus/parse-off-csv.mjs`.
- `shards/` — raw generation shards (exercises + enrichment batches), kept for rebuild/audit.

## Rebuild

```
node scripts/corpus/parse-fdc.mjs <srLegacyDir> <foundationDir> data/corpus/ingredients.json
node scripts/corpus/parse-off-csv.mjs <en.openfoodfacts.org.products.csv.gz> 20000 data/corpus/products.json
node scripts/corpus/merge-exercises.mjs && node scripts/corpus/apply-enrichment.mjs
node scripts/corpus/validate.mjs
```

Barcode lookups at runtime fall through to the OFF API for products outside this seed set (`scripts/corpus/fetch-off-products.mjs` is the API-based fetcher, kept as the incremental-refresh path).
