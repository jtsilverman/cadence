How it works — the six beats, assembled

SCROLL  the copy scrolls; the stage is one persistent board that carries through all six beats. Each beat triggers as its copy block reaches mid-viewport, plays through, then repeats on a ~4s idle. Scrolling back re-enters earlier states.

NUMBERS  every figure derives from one live data model. The target never moves: 1,900 · 150P · 185C · 62F. Surplus reads rust, on-or-under reads green.
